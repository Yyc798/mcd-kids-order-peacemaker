# 亲子沟通话术库（Skill 内部参考）

> 核心理念来自幼儿园一线带班经验：**孩子不是不讲理，是需要一个能"下台阶"的理由**。
> 直接拒绝（"不行"）会触发权力对抗；恐吓（"吃了会生病"）制造焦虑；贿赂（"吃完随便买"）养成交换习惯。
> 正确姿势：把选择权包装进食物自己的"故事"里，让孩子觉得是他自己做的决定。

## 一、分龄话术风格

### 3-5 岁：拟人童话体

食物有名字、有性格、有自己的"原因"。拒绝永远是"食物说了算"，不是"妈妈说了算"。

- 圣代 → "圣代雪人现在要冬眠啦，它说了下次凉快的时候再出来找你玩。"
- 可乐 → "可乐是个爱吵闹的小气泡，它会吵得你牙齿整晚睡不着。牛奶是安静的能量水，小队长都喝这个。"
- 巨无霸 → "这是大力士的汉堡哦！你现在是运蛋糕的小蚂蚁，先吃小堡堡，等你长成大力士，它整个都是你的。"
- 薯条 → "薯条小队长说它今天站岗太多啦，让玉米杯先替它的班。"
- 玩具 → "这个玩具说它想住在我们家的积分城堡里，我们回家用小星星（积分）把它请出来。"

### 6-8 岁：轻科普 + 电量任务体

把肚子变成"有格数的电量条"，数字让这个年龄段的孩子有掌控感。

- "你今天的小肚子还剩 2 格电量，薯条要占 5 格，装不下啦。麦乐鸡只要 2 格，刚刚好。"
- "牛奶是给骨头发工资的，可乐只发糖不给工资。今天已经发过工资啦。"
- "圣代和苹果派是同一个门派的，今天让苹果派出战，圣代周末再上场。"

### 9-10 岁：预算交底 + 谈判体

给真实信息和选择权，练"自己做取舍"。

- "这份预算是 80。巨无霸加可乐是 52，剩下的 28 不够你和妹妹的甜品。要么你俩分一个巨无霸，要么各点小堡。你决定。"
- "钠就是我们说的'咸味的量'，这个套餐的咸味量已经到了你今天额度的三分之二，再吃晚饭妈妈就要抢你的盐罐子了。"
- "玩具用积分换不用花钱，但我们账户只有 300 分。攒到 500 换大的还是现在换小的，你选。"

## 二、禁用话术（红线）

| 禁用类型 | 例句 | 为什么不行 |
|---|---|---|
| 恐吓式 | "再吃就生病住院" | 制造健康焦虑，且下次他会背着吃 |
| 羞辱式 | "都胖成球了还吃" | 食物羞耻是儿童饮食障碍的起点 |
| 贿赂式 | "乖，吃完这些都给你买" | 把食物变成交易筹码，越养越难谈 |
| 对比式 | "你看人家妹妹都不吃" | 伤自尊，且与食物本身无关 |
| 甩锅式 | "是叔叔说不卖的" | 孩子很快识破，消耗信任 |

## 三、现场急救三条（孩子已经在哭的时候）

1. **蹲下来，先共情不妥协**："你特别特别想要那个圣代对不对？"（先说出他的感受，情绪降温）
2. **给有限的二选一**："苹果派现在吃，还是我们吃完饭把积分攒起来周末换冰淇淋？你选一个。"（两个都可接受，夺回选择结构）
3. **守住底线但预告希望**："今天不买圣代，但你选的苹果派是全额通过。"（不翻旧账、不空洞许诺"下次"）

## 四、给家长的使用说明

- 话术直接照着念就行，**语气比词重要**：蹲平视线、慢慢说；
- 一次谈判只守一条底线（比如"饮料换牛奶"），全守会崩盘；
- 孩子接受交换后要**立刻兑现**，说到做到是这套话术的信用基础。
