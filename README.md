# 麦麦带娃点单安抚助手（mcd-kids-order-peacemaker）

> 带娃进麦当劳，最怕的不是排队，是孩子指着橱窗里的玩具和冰淇淋走不动路。
> 这个助手帮家长在三档清单里优雅"谈判"：**可以点 🟢 / 缓一缓 🟡 / 别点了 🔴**——每一档都用孩子听得懂的话来解释。

本项目是「麦当劳程序员创意开发大赛」参赛作品，基于麦当劳 MCP 能力 + 腾讯 WorkBuddy 智能体开发。

## 这解决什么问题

家长带 3-10 岁孩子吃麦当劳时的高频崩溃现场：

1. **孩子要的不能都给**——冰淇淋第 3 支了、快乐水喝完不吃饭，直接拒绝就是一场哭闹；
2. **家长不懂营养账**——哪份套餐钠超标？可乐换牛奶能省多少糖？说不出理由就只能靠吼；
3. **预算容易失控**——玩具、新品、加购一路叠加，结账才发现超了。

本助手把**儿童营养常识**（参照中国营养学会 DRIs 中 3-10 岁儿童推荐值）和**幼教沟通话术**（幼儿园老师同款"孩子听得懂的语言"）封装进一个 Skill，输入孩子年龄和预算，输出一份当场能用的点单方案。

## 核心能力

| 能力 | 说明 |
|---|---|
| 🚦 三档点单清单 | 按孩子年龄把想吃的分成「可以点 / 缓一缓 / 别点了」，附营养依据（能量、钠、添加糖） |
| 🗣️ 孩子听得懂的解释 | 每个拒绝理由都翻译成童话式语言："薯条小队长说它今天岗哨太多啦" |
| 🔄 平替交换方案 | 不说"不行"，说"换成这个可以吗"：可乐→牛奶、冰淇淋→苹果派分半、加玩具→用积分换 |
| 💰 预算守门员 | 结合优惠券与积分账户，实时算价，超预算自动给出"砍哪一单"建议 |
| 🏪 到店场景适配 | 支持到店 / 麦乐送 / 得来速三种场景，外送顺带查附近可配送门店 |

## 工作流程

```text
家长输入（孩子年龄 + 预算 + 场景 + 孩子点名要的东西）
        │
        ▼
① now-time-info        确认餐段（早餐/正餐菜单不同）
② query-meals          拉当前门店可售菜单
③ list-nutrition-foods 取餐品营养数据（能量/钠/糖）
④ query-my-coupons     查可用优惠券
⑤ query-my-account     查积分（可换玩具/甜品吗）
⑥ calculate-price      按方案实算总价，卡预算线
        │
        ▼
输出：三档清单 + 亲子话术 + 总价与优惠明细
```

全程只读查询 + 价格试算，**不自动下单**；是否下单、付款永远由家长本人完成。

## 安装方法

### 1. 领取麦当劳 MCP Token

- 登录 [麦当劳 MCP 开放平台](https://open.mcd.cn/mcp)（手机号验证登录）
- 点右上角「控制台」→「激活」申请 MCP Token（免费）

### 2. 接入你的 MCP 客户端

在 MCP 客户端（WorkBuddy / Cherry Studio / Cursor 等）中添加配置，把 `YOUR_MCP_TOKEN` 替换为你的真实 Token：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

（完整脱敏示例见 [mcp-config.example.json](./mcp-config.example.json)，Token 建议放环境变量。）

### 3. 安装 Skill

- **WorkBuddy 用户**：把 `skill/` 目录作为自定义 Skill 导入（或按 WorkBuddy 自定义连接器方式添加 mcd-mcp 后，将 SKILL.md 内容贴入自定义技能）；
- **其他 MCP 客户端用户**：直接把 `skill/SKILL.md` 的内容粘贴进系统提示词/自定义指令即可。

## 使用示例

```text
我：晚上带 5 岁的娃去麦当劳，预算 80，他点名要巨无霸+可乐+冰淇淋圣代，
    帮我安排一下。

助手：
🟢 可以点：麦乐鸡(4块) + 牛奶 + 玉米杯
   ——"麦乐鸡小队今晚在等你检阅！牛奶是给小队长补充能量的蓝色能量水。"

🟡 缓一缓：冰淇淋圣代 → 换成苹果派两人分
   ——"圣代雪人要冬眠了，苹果派先替它站岗，下周末雪人睡醒再来看你。"

🔴 别点了：巨无霸（双层牛肉对一个 5 岁小朋友太多啦）+ 可乐
   ——"巨无霸是大力士的汉堡，你现在是运蛋糕的小蚂蚁，先吃小堡堡，
     长成大力士那天它就是你的了。可乐医生说它太吵，会吵得牙齿睡不着。"

💰 预算：原价 92 元，用你账户里的「麦乐鸡买一送一」券后 71 元 ✓
```

## 目标用户

- **3-10 岁孩子的家长**——核心用户，尤其是"讲道理讲不过三岁人类"的那种；
- **幼儿园/小学教师**——组织亲子活动、麦当劳主题生日会时快速配餐；
- **隔代喂养的长辈**——话术卡直接念给孩子听，比"再哭就不要你了"管用。
